# MathStack Landing Page


Aplicación móvil de aprendizaje adaptativo enfocada en el fortalecimiento de habilidades matemáticas para estudiantes universitarios.

## Descripción

MathStack permite identificar áreas de oportunidad mediante evaluaciones diagnósticas y generar rutas de aprendizaje personalizadas para reforzar conocimientos en distintas áreas de las matemáticas.

La plataforma integra elementos de gamificación para incentivar la práctica constante y mejorar la experiencia de aprendizaje.

## Características

* Evaluación diagnóstica inicial.
* Rutas de aprendizaje personalizadas.
* Lecciones y ejercicios interactivos.
* Sistema de experiencia y niveles.
* Rachas diarias de estudio.
* Monedas virtuales e insignias.
* Seguimiento del progreso académico.
* Retos matemáticos entre usuarios.

## Tecnologías

### Aplicación móvil

* Kotlin
* Jetpack Compose
* Material 3
* Hilt
* Room Database

### Backend

* Ktor
* PostgreSQL
* JWT
